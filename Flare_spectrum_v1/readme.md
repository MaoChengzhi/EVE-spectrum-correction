# Flare Spectrum v1

This folder contains scripts and data for exploring how EVE spectral line parameters change during solar flares.

Only a little effort has been devoted to this section.

- Motivated by the observation that the FWHM of the He II 304 Å line decreases during some flares.
- Collected data for multiple flares and spectral lines to analyze changes in FWHM, amplitude, and line center during flare events.
- Data files in the `data/` folder include selected spectral bands, flare observations, and wavelength information.


Next steps might include doing simple statics for those solar eruptions about whether CME are present and the locations on the solar surface.
