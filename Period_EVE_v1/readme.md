# Period_EVE_v1

This section builds on the daily wavelet results obtained in Chapter 4 v3.



- Uses daily median values of spectral line parameters (one point per day) as input.
- Explores hidden information in the wavelet transformation results.
- Combines the global wavelet spectra (GWS) of all lines to search for global periodicities across lines of different temperatures (heights).




No clear global periodicity trends with respect to temperature were found. This work marks the conclusion of my bachelor thesis and this phase of the project.
