# Chapter4_day

This folder contains initial scripts and notebooks for processing and analyzing AIA and EVE data together.  

This section is about a short-term comparison (6 hours of AIA at 10s cadence and 1 day of EVE at 10s cadence) to explore their relationship.  

This analysis served as a starting point for further attempt on exploring relationship between AIA and EVE, as well as longer-term studies.
